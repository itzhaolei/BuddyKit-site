BUILT AROUND THE THINGS YOU ACTUALLY DO

少一点管理，
多一点专注。

浏览器 OAuth 授权、账号卡片、本地会话归属和用量统计，加上每日积分自动领取。关闭窗口后继续在后台运行；明确退出 BuddyKit 后停止领取。

01 / ACCOUNT SWITCHING
◎

账号卡片，一眼识别

昵称、账号类型、订阅类型和剩余积分都来自 WorkBuddy 当前数据。卡片配色按账号固定，下次启动仍然保持一致。

PersonalFree剩余积分
02 / SESSION OWNERSHIP
↗

活跃本地任务跟随切换

空闲时保持 WorkBuddy 运行；有运行任务时强制关闭，切换后重开。活跃本地会话的置顶、顺序与分组一并保留，已删除、归档及云端会话不迁移。

active local sessions→selected account
03 / USAGE INSIGHT
▦

积分与 Token，看得明白

账号卡片的剩余积分每秒刷新。每日看板展示真实的积分和 Token 用量，可悬浮查看某一天的精确数量，并支持切换月份。

今日昨日本月今年
04 / BROWSER OAUTH
↗

官方浏览器授权

点击“添加账号”后唤起 WorkBuddy 官方授权页。验证完成，BuddyKit 读取账号信息并生成卡片，不需要手动输入账号名。

WorkBuddy→BuddyKit
05 / DAILY CREDITS
＋

每日加油站，自动领取

按北京时间 07:00–09:00 为每个已授权账号分别随机安排每日领取，卡片展示下次签到时间；休眠或离线后延后补领，无需切换 WorkBuddy。

每天自动领取领取状态可见
06 / BACKGROUND RUNNING
◉

关掉窗口，继续代领

点击红色关闭按钮后隐藏到后台，可从菜单栏、系统托盘或 macOS Dock 重新打开。选择“退出 BuddyKit”后停止领取，不创建系统任务，也不开机自启。

关闭窗口继续运行退出即停止

LOCAL BY DEFAULT

你的登录状态，
留在你的电脑上。

账号快照在本地以 AES-GCM 加密保存。BuddyKit 不使用系统钥匙串，不启动本地服务，不上传账号列表；通过 WorkBuddy 官方页面授权，并使用官方接口查询与领取积分。
